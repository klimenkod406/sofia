# Sofia – AI-Powered Study Companion

An intelligent study assistant that helps students learn more effectively through personalized question generation, spaced repetition scheduling, and active recall techniques.

**Goals:**
- Generate practice questions from study materials (PDFs, notes, textbooks) using AI
- Implement spaced repetition algorithm to optimize review timing based on performance
- Track learning progress with analytics on weak topics and mastery levels
- Support multiple question formats: multiple choice, flashcards, fill-in-the-blank
- Provide explanations for incorrect answers to reinforce understanding
